# Fiscal Module Audit — 26/08/2026

## High Severity
### 1. Public endpoints: electronic_voucher_book_create/edit/delete
- Views lack @login_required.
- Mounted under /api/ in config/urls.py.
- Anonymous users can create/edit/delete AFIP voucher-book configuration.

### 2. fiscal_invoice_create trusts sale_id
- Uses get_object_or_404(Sale, id=sale_id) without company ownership validation.
- Any logged-in user can generate fiscal invoices and journal entries for another company by guessing IDs.

## Medium Severity
### 3. Race condition in FiscalInvoice.next_number()
- Reads latest invoice and increments without locking.
- Concurrent requests can generate duplicate invoice numbers.
